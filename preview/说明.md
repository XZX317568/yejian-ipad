# 自己试一下（Windows 桌面预览）

双击任意 `.cmd` 就会打开阅读器，里面已放好 5 本样书（山海之间 / 深蓝来信 / 雨后列车 / 小镇回声 / 月光旅人）。

| 文件 | 用什么参数 |
|---|---|
| 试-A-基线.cmd | 参考实现原值 |
| 试-B-更拔.cmd | 抽得更远、飞得更高、倾角更大 |
| 试-C-更克制.cmd | 抽得近、几乎不倾 |
| 试-自己调参数.cmd | 读 `params-随意调.json`，改完不用编译 |

## 试什么（30 秒）

1. **书架上下滚动**：看两侧书是否"下沉"、中间那本是否被"拔出"
2. **点中间那本书**：书离开书架、飞向你的那一段（A/B/C 主要差别在这）
3. **详情页点「开始阅读」**：翻页时纸张的弯曲

## 想自己调数

记事本打开 `params-随意调.json`，改完关窗口、再双击 `试-自己调参数.cmd`。**不需要编译。**

```json
"shelf": { "pull_base": 0.84, "lift_px": 18, "roll_rad": 0.045, "arc_base": 12 },
"paper": { "base": 17, "arch": 7, "breeze_gain": 3 }
```

- `pull_base` 抽出距离｜`lift_px` 飞起高度｜`roll_rad` 倾角（0.05≈2.9°）
- `paper.base` 纸张弯曲强度，改 **0** 就是完全平的纸，能直接感受差别

## 如果书架是空的

启动器传的是 `--data-dir "%~dp0data\library"`（程序要的是**库目录本身**，不是它的父目录）。若仍为空，说明这份样书库的数据没被识别，双击后在设置里用「导入漫画」选 `preview\data\fixtures` 里的 5 个 cbz 即可。

## 注意

- 这是 **Windows 桌面构建**，不是 iPad：触摸手感与真实帧率看不出来，但抽书/摊开/翻页的**节奏、比例、弯曲**是同一套代码
- 数据都在 `preview/data`，与真实书库隔离；想重置就删掉该目录再运行
